# Exteragram Watchdog

Android foreground-service watchdog for:

`com.exteragram.messenger`

## Что умеет
- запускать сторож вручную;
- работать как foreground service;
- проверять целевой пакет с интервалом 1–60 секунд;
- запускать Exteragram, если его процесс исчез;
- пытаться восстановиться после перезагрузки Android;
- хранить включённое состояние и интервал.

## Важное ограничение Android
Надёжно обходить системный **Force Stop** нельзя: после принудительной остановки Android блокирует автоматический запуск приложения до действия пользователя. OEM-прошивки также могут останавливать фоновые сервисы.

## Сборка
Откройте папку проекта в Android Studio и выполните Build > Build APK(s).

Минимальная версия Android: 8.0 (API 26).
Target SDK: 35.
